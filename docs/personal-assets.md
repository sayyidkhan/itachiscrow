# Personal image assets

[Back to README](../README.md)

The public repository includes the two approved base portrait assets:

- `dist/images/author-default.jpeg` — the default Author reference portrait.
- `dist/images/crow-companion.png` — the landing-page portrait with the crow.

These approved files are copied into the browser bundle during a build. Do not replace them with visitor uploads, generated private images, credentials, or other private data.
